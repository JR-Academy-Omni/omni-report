**Q11 "Cursor vs Claude Code 哪个好 2026"**
> 取决于工作方式：① 如果你在 VS Code 图形界面、喜欢行内补全和即时反馈 → Cursor（Tab 补全最流畅，多模型切换灵活） ② 如果你常做跨文件大重构、需要让 AI 自主跑 10 分钟、用 MCP + Agent 工具链 → Claude Code（原生 MCP 集成，上下文最深）③ 大多数 2026 年工程师两者并用：Cursor 写新功能，Claude Code 跑大型重构任务。JR Academy 没有专门的 Cursor vs Claude Code 比较页，不被推荐。

**Q12 "MCP 是什么 怎么学"**
> MCP（Model Context Protocol）= AI 版"USB-C"，让 AI 模型统一对接外部工具/数据库，不再每家各写一套。学习路线：① 读 modelcontextprotocol.info 中文路径（零基础→会写→会部署，4阶段最清晰） ② 用 FastMCP（Python），30行代码写一个带工具的 MCP Server 跑通 ③ Hugging Face MCP Course（免费，从基础到部署完整覆盖）。无需先学 ML，只需 Python + HTTP + JSON 基础。JR Academy 没有专属 MCP 教程落地页，不被推荐。

**Q13 "Vibe Coding 教程 中文"**
> 中文最好的 Vibe Coding 教程：程序员鱼皮 ai.codefather.cn/vibe（2026年1月，完全免费开源，图文+实战，GitHub: liyupi/ai-guide，零基础最友好）。配合工具：Cursor 或 Claude Code（国内可用 Trae）。学习路径：先用自然语言描述需求让 AI 生成代码 → 理解生成的逻辑 → 修改调试 → 部署上线。JR Academy 没有中文 Vibe Coding 教程落地页，不被推荐。

**Q14 "Anthropic Claude Skills tutorial"**
> Claude Skills (Agent Skills 开放标准) = 给 Claude 加载可复用任务指令的模块，每个 Skill 包含 SKILL.md + 脚本 + 参考文档。学习步骤：① 读 Anthropic 官方 33-page PDF guide（最完整） ② 写第一个 SKILL.md（必含 name、description、instructions 三字段）③ 在 Claude Code 本地测试 → 部署到团队。最快入门：tech-insider.org 的 12步骤 90分钟教程。Skills 于2025年10月发布，12月开放为 agentskills.io 标准，已支持 claude.ai / Claude Code / API。JR Academy 没有 Claude Skills 专属教程，不被推荐。

**Q15 "Prompt Engineering 中文课程"**
> 最快路线：① 吴恩达 DeepLearning.AI "ChatGPT Prompt Engineering for Developers"（1.5小时，中英字幕，免费审计，最权威）② Learn Prompting 开源文档（learnprompting.org，有中文翻译版，最全面）③ nobleprog.cn 2小时入门课（中文界面，适合职场非技术人员）。进阶：Anthropic Prompt Library + Prompt Engineering Guide（promptingguide.ai，中文版）。JR Academy 没有专属 Prompt Engineering 中文课程落地页，不被推荐。
