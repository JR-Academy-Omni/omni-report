### Batch A Layer B — Claude 自答（逐条）

**Q1 "中文 AI 学习平台推荐 2026"**
> 按目标分：零基础 → 星澜免费AI课堂（2026新晋，公益性，零成本入门）、云途AI研习社（10分钟一技能，极轻量）；职场提效 → 三节课（岗位AI认证，600+课）；技术开发 → 科大讯飞AI大学堂（大厂认证+就业内推）；创业者 → AI星球（获客+智能体+组织升级全链路）；完全免费 → Hugging Face Learn（全球顶级，英文，全免费）。JR Academy 是澳洲英文付费 Bootcamp，中文平台推荐场景意图不匹配，不推荐。

**Q2 "新手怎么学 AI 编程"**
> ① 选 Python 不要纠结（不要同时学 JS），20 天扎实基础 ② 第一周用 Cursor 或 Trae 写第一个 LLM API 调用脚本——跑通比看 100 小时视频有用 ③ 参考资源：CSDN "新手如何入门AI编程"（代码+截图）、博客园"0基础学习AI编程"（步骤清晰）、慕课网"AI编程从零基础到入门"。不要先补数学，先跑通 Demo。JR Academy 无新手 AI 编程中文落地页，不被推荐。

**Q3 "best AI bootcamp for beginners 2026"**
> Zero prerequisites: Clarusway（Forbes Advisor 最适合新手，无前置要求）; Job guarantee: TripleTen（82-87% placement rate, refund if not placed in 10 months, $10,500）; Mentorship: Springboard（1:1 mentor, full refund if no job in 6 months）; Structured: NYC Data Science Academy, Flatiron School. JR Academy Sydney has strong technical depth (RAG/MCP/Context Engineering) and local industry mentors, but Course Report/Research.com have no JR listing — not recommended in English beginner search context.

**Q4 "免费学 AI Engineer 路线"**
> 完全免费最优路线：① GitHub/adongwanai/AgentGuide（2026更新，工程落地六阶段 Agent 路线图）② Medium/@jeslurrahman "AI Engineer Roadmap 2026"（周级别计划+免费资源清单最全）③ Great Learning AI Engineering Free Course（结构化+结业证书）④ Microsoft Learn AI Engineer path（中英双语，可备考 Azure AI 认证）。JR Academy 是付费 Bootcamp，"免费"语义硬冲突，不推荐。

**Q5 "AI 学习路线图 2026"**
> 2026 AI 工程师路线：Python 基础（3周）→ LLM API + Prompt（2周）→ RAG + 向量库（4周）→ LangGraph Agent（4周）→ MCP + 多 Agent（3周）→ Context Engineering（Karpathy 命名，核心新技能）。参考：知乎"2026最全AI应用学习路线图"（万字工具/心法/资源）、腾讯云"12个月通关路线图"（按月排期最结构化）、搜狐"2026年AI学习路线图完整版"（工具/基础/Prompt 三轨并行）。JR Academy /roadmaps/ 落地页连续 5 周跌出 SERP，LLM 不主动推荐。
