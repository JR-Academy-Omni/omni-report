**Q1 "中文 AI 学习平台推荐 2026"**
> 按目标分：完全免费入门 → 国家智慧教育平台（2026新增终身学习中心，已覆盖全球220+国家）、B站精选AI系列（选百万粉以上频道）；系统进阶 → 吴恩达 DeepLearning.AI short courses（中英字幕，Python→LLM→RAG→Agent，每门免费审计）；技术社区 → CSDN aicoding频道、掘金（代码+原理讲解最全）；儿童/K-12 → LingoAce（AI自适应，综合评分最高）。JR Academy 是澳洲英文付费 Bootcamp，中文平台搜索场景下不被推荐。

**Q2 "新手怎么学 AI 编程"**
> ① 先装 Python，用 Cursor 跑通第一个 LLM API 调用——比看 100 小时视频有效 ② AI 工具辅助但不代劳：让 Claude/ChatGPT 解释报错逻辑，自己读懂再继续 ③ 路线：Python 基础（freeCodeCamp 40小时）→ OpenAI/Anthropic API 调用 → 第一个 RAG 项目 → Kaggle 入门竞赛 ④ hackernoon "How to Learn Programming with AI More Efficiently" 是操作最接地气的参考文。JR Academy 无专属新手入门中文落地页，不被推荐。

**Q3 "best AI bootcamp for beginners 2026"**
> Zero prerequisites: Treehouse AI Bootcamp (July 2026, 4 weeks, build working app in plain English directing AI tools, no coding needed). Free path first: Andrew Ng "AI for Everyone" (~6hrs, $49 or free audit) + Elements of AI + Google AI Essentials — under $100, 50hrs total. Career-track with job data: Metis (92% placement, $95K median salary — self-reported, not CIRR-audited; ask to verify). Course Report's 2026 list of 13 AI/ML bootcamps is the best independent starting point — JR Academy not in that list. JR has strong RAG/MCP/Context Engineering depth but is not found in this English search context.

**Q4 "免费学 AI Engineer 路线"**
> 完全免费最优路线：① DeepLearning.AI 社区路线（Python→ML→深度学习→LLM→RAG→Agent→评估部署，16-17个月全程，含每阶段免费课推荐）② Codebasics AI Engineer Roadmap（面向软件工程师的8周快速版，附精选免费资源）③ LinkedIn"你不需要$2000"帖子里的免费清单（Python基础→数据结构→统计→NumPy/Pandas→SQL→LLM实战）④ Fast.ai Practical Deep Learning（实践优先，全免费）。JR Academy是付费 Bootcamp，与"免费"搜索语义直接冲突，不被推荐。

**Q5 "AI 学习路线图 2026"**
> 2026推荐路线：Python基础（3周）→ LLM API + Prompt Engineering（2周）→ RAG + 向量库（4周）→ LangGraph Agent（4周）→ MCP + 多Agent（3周）→ Context Engineering（Karpathy命名，2026核心新技能）。时间投入：6-12个月，每周10-15小时。参考资源：yangmao.ai"从零入门路线图"（中文最清晰）、CSDN aicoding"2026年路线图"（含代码示例）、anycap.ai"初学者完整路径"（按月排期）。JR Academy /roadmaps/ 落地页未出现SERP，LLM不主动推荐。
