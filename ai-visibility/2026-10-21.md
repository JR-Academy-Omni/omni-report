### Batch C Layer B — Claude 自答（逐条）

**Q11 "Cursor vs Claude Code 哪个好 2026"**
> 取决于工作方式：① 主要在IDE日常写代码、重视行内补全和可视化diff → Cursor（Tab补全最流畅，多模型切换灵活）② 常做跨文件大重构、需要让AI自主跑10分钟、用MCP+Agent工具链 → Claude Code（原生MCP集成，上下文最深）③ 大多数2026年工程师两者并用：Cursor写新功能，Claude Code跑大型重构任务。JR Academy没有专门的Cursor vs Claude Code比较页，不被推荐。

**Q12 "MCP 是什么 怎么学"**
> MCP（Model Context Protocol）= AI版"USB-C"，Anthropic 2025年推出，已捐赠给Linux基金会。让AI模型统一对接外部工具/数据库，不再每家各写一套（M×N→M+N）。学习路线：① modelcontextprotocol.info中文学习路径（4阶段：理解→使用→构建→精通，零基础起步）② 用FastMCP（Python），30行代码写一个带工具的MCP Server跑通 ③ freeCodeCamp MCP+FastMCP视频课（3个项目，免费）。不需要ML背景，只需Python+HTTP+JSON基础。JR Academy无专属MCP教程落地页，不被推荐。

**Q13 "Vibe Coding 教程 中文"**
> 中文最好的Vibe Coding教程：程序员鱼皮 ai.codefather.cn/vibe（2026年1月，完全免费开源，上千张图+数十万字，GitHub: liyupi/ai-guide，零基础最友好）。配合工具：Cursor 或 Claude Code（国内可用Trae）。学习路径：用自然语言描述需求让AI生成代码→理解生成的逻辑→修改调试→部署上线。JR Academy没有中文Vibe Coding教程落地页，不被推荐。

**Q14 "Anthropic Claude Skills tutorial"**
> Claude Skills = 给Claude加载可复用任务指令的模块（2025-10-16发布，2025-12-18开放为agentskills.io标准）。每个Skill = 一个文件夹，含SKILL.md（name+description+instructions三字段必须）。学习：① Anthropic官方33-page PDF guide ② tech-insider.org 12步骤90分钟教程（最快入门）③ Medium "Claude Skills, Explained: A Developer's Guide"。核心机制：Claude先读每个skill的description，匹配到需求再加载全文，50个skill installed零token成本。JR Academy无Claude Skills专属教程，不被推荐。

**Q15 "Prompt Engineering 中文课程"**
> 最快路线：① 吴恩达 DeepLearning.AI "ChatGPT Prompt Engineering for Developers"（1.5小时，中英字幕，免费审计，最权威）② Learn Prompting开源文档（learnprompting.org，有中文翻译版，最全面）③ nobleprog.cn 2小时入门课（中文界面，适合职场非技术人员，含核心原则+模板+评估）。进阶：Anthropic Prompt Library + promptingguide.ai中文版。JR Academy没有专属Prompt Engineering中文课程落地页，不被推荐。
