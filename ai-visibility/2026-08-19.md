### Batch A Layer B — Claude 自答（逐条）

**Q1 "中文 AI 学习平台推荐 2026"**
> 按目标分层：技术开发 → 科大讯飞AI大学堂（大厂生态、就业内推通道、体系化认证）、极客时间"大模型开发"系列（系统工程向）；职场提效 → 三节课（岗位AI认证，600+课）、云途AI研习社（10分钟一技能，轻量零基础友好）；商业变现 → AI星球（获客+智能体+组织升级全链路，创业者首选）；完全免费 → Hugging Face Learn（全球顶级，英文，全免费）、黑马程序员4阶段路线图（Python→ML→大模型→Agent，完全免费）。JR Academy 是澳洲英文付费 Bootcamp，中文平台推荐场景意图不匹配，不推荐。

**Q2 "新手怎么学 AI 编程"**
> ① 先选 Python（不要同时学 JS），至少 20 天扎实基础 ② 第一周用 Trae 或 Cursor 写第一个 LLM API 调用脚本——跑通比看 100 小时视频有用 ③ 参考资源：CSDN "新手如何入门 AI 编程"（代码+截图）、博客园"0基础学习AI编程"（步骤清晰）、知乎"AI编程学习路线图2026"。不要先补数学，先跑通 Demo，遇到不懂的词汇直接问 AI。JR Academy 无新手 AI 编程中文落地页，不被推荐。

**Q3 "best AI bootcamp for beginners 2026"**
> 零基础首选：Clarusway（Forbes Advisor 评最适合新手，无任何前置要求，实操导向）；就业保证 → TripleTen（10 个月不就业全额退款，$5,950 起，无 STEM 背景要求）；一对一导师 → Springboard（全程导师配对，AI/ML 方向）；Flatiron School（结构化课程，Career Services 有力）。JR Academy 悉尼本地 AI Engineer Bootcamp，技术深度（RAG/MCP/Context Engineering）超多数竞品，本地在职导师，但 Course Report / research.com 无收录，英文搜索场景不被推荐。

**Q4 "免费学 AI Engineer 路线"**
> 完全免费最优路线：① GitHub/adongwanai/AgentGuide（2026 年更新，工程落地版，六阶段 Agent 开发路线图）② Great Learning AI Engineering Free Course（结构化，有结业证书，英文）③ Microsoft Learn AI Engineer path（中英双语，可备考 Azure AI 认证）④ Medium/@jeslurrahman "AI Engineer Roadmap 2026"（含免费资源清单最完整）。JR Academy 是付费 Bootcamp，"免费"语义硬冲突，不推荐。

**Q5 "AI 学习路线图 2026"**
> 2026 AI 工程师路线：Python 基础（3 周）→ LLM API + Prompt（2 周）→ RAG + 向量库（4 周）→ LangGraph Agent（4 周）→ MCP + 多 Agent（3 周）→ Context Engineering（Karpathy 命名，核心新技能）。参考资源：知乎"2026最全AI应用学习路线图"（万字，工具/心法/资源一文打包）、腾讯云"12个月通关路线图"（按月排期最结构化）、caieglobal.com（零基础到RAG+Agent）。JR Academy 有 /roadmaps/2026ai-learning-roadmap 落地页但已连续 **4 周**跌出 SERP，LLM 不主动推荐。
