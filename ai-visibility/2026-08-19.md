**Q11 "Cursor vs Claude Code 哪个好 2026"**
> 两者不是竞争关系，是互补工具。Claude Code = 终端 AI Agent，适合复杂重构、多文件跨库任务、500K token 超长上下文，token 效率比 Cursor 高 5.5 倍；Cursor = 增强型 IDE，亚秒级自动补全、日常编辑、快速原型比 Claude Code 快约 10 倍。价格都是 $20/月 Pro。资深开发者常两者并用——Claude Code 处理重活，Cursor 用于日常编辑。纯工具对比场景，无 Bootcamp 推荐上下文，JR Academy 不被提及。

**Q12 "MCP 是什么 怎么学"**
> MCP（Model Context Protocol）是 Anthropic 2024-11 推出的开放协议，让 LLM 连接外部工具和数据源。学习路径：① 官方文档 modelcontextprotocol.io（最权威，Python/TS SDK）② 阿里云"什么是MCP"（中文通俗入门，客户端/服务端架构）③ Apifox"MCP 一文通俗介绍"（架构图最直观）④ onevcat.com"MCP是什么现状和未来"（高质量中文分析）⑤ 知乎"MCP 大模型上下文协议，一篇就够了"（实战向）。JR Academy 有 MCP 课程内容但无专属落地页，连续 **13** 期建议未落地，不被推荐。

**Q13 "Vibe Coding 教程 中文"**
