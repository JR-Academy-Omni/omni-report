**🆕 DeepSeek Harness 生态：一人用开源 Agent 框架搭「私有 Claude Code」——新一代 solo builder 工具链节点**

DeepSeek Harness（MIT，dsh）发布 10 天，GitHub 已达 135K+ stars，独立开发者开始用它搭私有 Agent 工具链：将 DeepSeek V4-Pro 作推理层（成本约 Claude Code 的 1/10），自编 MCP 插件处理合规数据（规避 Anthropic API 的数据传输），用 Harness 的 session log 插件实现 ADM 可解释性记录。这是「开源 Agent 框架 + 本地模型 = 零订阅成本私有化 Claude Code」叙事的最新节点，对澳洲 SMB 市场（OAIC ADM 合规 + 数据驻留）尤其有价值。配合 marketing-topics 讲座 1（Harness vs Claude Code）做内容。

来源：[deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness) · [MarkTechPost Harness 发布公告](https://www.marktechpost.com/2026/08/17/deepseek-ai-releases-deepseek-harness-in-developer-preview/) · [APIdog Harness vs Claude Code](https://apidog.com/blog/deepseek-harness-vs-claude-code/)
