2026 澳洲黑五是 11 月 27 日，Cyber Monday 是 11 月 30 日。别只盯电脑和家电，这波更值得蹲的是课程、证书和学习会员📚

2️⃣ Coursera Plus｜年费 8 折

官方 Promo 页显示首年 US$330→US$165，含 800+ 门 AI、Python、SQL、Power BI 课程及项目。

4️⃣ Udemy｜2026 黑五专题已上线

AI、Python、Excel、认证备考都已进入专题，但官方尚未统一公布折扣比例和结束时间。不同账号可能显示不同价格，只认自己的结账页。

5️⃣ DataCamp Student｜年费 5 折 / 月费 7 折

澳洲在读大学生可用学校邮箱验证；学生价不能与其他促销叠加。

6️⃣ DataCamp × GitHub Student Pack｜3 个月免费

通过 GitHub 学生认证、且不是现有 DataCamp 订阅用户，可领 3 个月课程库访问，不绑信用卡，每人一次。

7️⃣ Educative｜6 个月免费 + 订阅 7 折

GitHub Student Pack 提供 70+ 门 Web、Python、Java、Machine Learning 课程免费访问 6 个月，之后购买订阅可减 30%。

8️⃣ Frontend Masters｜全站课程免费 6 个月

同样需要 GitHub Student Pack，适合学 JavaScript、Node.js 和前端工程。

9️⃣ Boot.dev｜完整会员免费 3 个月

覆盖 Python、Go、TypeScript、Backend、DevOps 和 Data Analysis，需通过 GitHub 学生资格领取。

🔟 Codédex Club｜高级会员免费 6 个月

适合从 Python、HTML、CSS、JavaScript、React 和 Git 入门，限已验证学生。

1️⃣1️⃣ O’Reilly Learning｜免费试用 10 天

不用绑信用卡，可访问技术书、视频课、Live Events、互动实验和认证备考资料。它不是黑五折扣，但适合先集中试学再决定。

1️⃣2️⃣ LinkedIn Learning｜符合资格可试用 1 个月

可学 26,000+ 门课程并获得课程完成证书；试用到期会自动转付费，开通当天记得设提醒。

⚠️ Skillshare、MasterClass、edX 目前仍未查到 2026 黑五官方条款。现在看到“全年最低”“限时 80% off”，先核对官网日期、澳洲适用范围和续费价。

建议先收藏，11 月中下旬再回来核一次价。真正要比的不是折扣数字，而是课程是否包含证书、优惠是否限新用户、订阅会不会自动续费，以及自己一年到底学不学得完。
