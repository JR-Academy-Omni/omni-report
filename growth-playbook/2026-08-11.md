## §本周不推荐

**1. 「Qwen3.8 Max vs GPT-5.6 Luna 账单晒出来」活动**
模型价格战本周确实热度高，但"晒账单"的参与者画像是已在用 API 的开发者——他们在 HN 讨论，不是付费 Bootcamp 学员。上期（08-04）「Sonnet 5 28 天 API 成本打卡」已覆盖这个方向；本周重复做会稀释话题新鲜感，且没有等效的触发叙事（上期有"涨价倒计时"作为催化剂，本周没有）。

**2. 「澳洲 AI 岗位 1,298 个」纯数据海报宣传**
数据本身有吸引力，但单纯发静态数据海报不产生 action——看完就走，不留资、不裂变。这组数据最好的用法是作为玩法③（Maven 截流对比文）的信任背书锚点嵌入在落地页里，而不是单独作为一个增长玩法。
