### 1. 【近 7 天仍在发酵｜产品上线｜2026-09-10】ChatGPT 金融服务版上线，内置专业数据与 GPT‑6 Astra

- 发生了什么：OpenAI 于 `2026-09-10` 推出 `ChatGPT for Financial Services`，把 `GPT‑6 Astra`、金融分析工具以及 Daloopa、PitchBook、LSEG News 等专业数据直接整合进 ChatGPT Work，首批聚焦投行与股票研究。
- 为什么重要：金融团队无需分别采购连接器、搬运数据和核对出处，就能在同一环境完成研究、财务建模与客户材料；产品还提供细粒度引用，方便追溯数字和结论。
- 一句话点评：行业 AI 的竞争，正在从“懂金融术语”升级为“把可信数据、推理和交付模板装进同一个工作台”。
- 来源：[OpenAI：Introducing ChatGPT for Financial Services](https://openai.com/index/introducing-chatgpt-financial-services/)

### 2. 【近 7 天仍在发酵｜模型发布｜2026-09-10】Skild S1 看一段视频，即可学习最长十分钟的新任务

- 发生了什么：NVIDIA 于 `2026-09-10` 介绍 Skild AI 新发布的 `S1` 机器人基础模型。操作员只需录制一段示范视频，模型便能在不更新权重、不做任务专门后训练的情况下理解并执行陌生长流程任务，单次任务最长约 `10 分钟`。
- 为什么重要：官方披露的测试中，S1 在新多步骤任务上的逐步成功率约 `66%`，对比系统约 `9%`；一个短视频示例的效果估算相当于约 `380` 次实体训练样本，可显著降低机器人换线和重编程成本。
- 一句话点评：具身智能真正进入工厂的关键，不是会做一次演示，而是新任务来时能否少采数据、少停产、快速学会。
- 来源：[NVIDIA：Skild AI Taps NVIDIA Physical AI to Teach Robots New Tasks From a Single Video](https://blogs.nvidia.com/blog/skild-ai-s1-physical-ai/)

### 3. 【近 7 天仍在发酵｜平台安全｜2026-09-10】OpenAI 项目 API 密钥新增到期与最长寿命控制

- 发生了什么：OpenAI 于 `2026-09-10` 为项目 API 密钥上线到期时间设置，并允许管理员在组织或项目层强制规定密钥最长寿命；新创建的密钥必须在策略期限内失效。
- 为什么重要：长期有效密钥一旦泄露，风险窗口很难收口。平台原生的到期和最长寿命策略，让企业可以把密钥轮换从人工提醒变成统一强制控制。
- 一句话点评：Agent 能力越强、调用面越广，密钥治理越不能只靠文档和自觉。
- 来源：[OpenAI Release Notes：Project API key expiration and maximum lifetime controls](https://openai.com/products/release-notes/)
