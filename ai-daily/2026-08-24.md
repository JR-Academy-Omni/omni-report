## 日报正文

### 1. 【AI 基建 / 模型工厂｜2026-08-23】Nvidia 豪掷 60 亿美元拿下 Poolside 授权，并追加 10 亿美元投资

- 发生了什么：据《华尔街日报》`2026-08-23` 报道，Nvidia 与 AI 初创公司 `Poolside` 达成一笔约 `60 亿美元` 的授权交易，用于打造美国本土更强的 `open-weight` 模型体系；Nvidia 还将对 Poolside 追加 `10 亿美元` 投资，并吸收 `100+` 名工程师加入 `Nemotron` 相关研发。
- 为什么重要：这不是普通参股，而是芯片公司直接下场补“模型层”短板。美国在开源权重模型上的竞争压力最近明显抬升，Nvidia 这步相当于把算力、资本和模型路线绑到一起。
- 一句话点评：当 Nvidia 不只卖铲子、还开始自己组矿队，AI 基建竞争就进入下一阶段了。
- 来源链接：
  - [The Wall Street Journal：Nvidia Is Spending $6 Billion to Build a Powerful U.S. Alternative to Chinese AI](https://www.wsj.com/tech/ai/nvidia-is-spending-6-billion-to-build-a-powerful-u-s-alternative-to-chinese-ai-c51c38cc)

### 2. 【近7天仍在发酵｜产品更新｜2026-08-20】OpenAI 把 Apple Messages、Codex 聊天分享和 ChatGPT Sites URL 改名一起推进

- 发生了什么：OpenAI 在 `2026-08-20` 的 `ChatGPT Release Notes` 中更新了多项入口级能力：`Codex` 和 `ChatGPT Work` 现可在 Apple silicon Mac 上通过 `Apple Messages` 插件读写 `iMessage`、`SMS`、`RCS`；`Codex` 新增只读分享链接；`ChatGPT Sites` 支持直接修改 ChatGPT 托管 URL 且旧地址可自动重定向；`Computer History` 也扩展到了 `EEA`、`Switzerland` 和 `UK` 的 `Pro` 用户。
- 为什么重要：这不是零散小修，而是 OpenAI 在继续把 ChatGPT / Codex 从“会话框”推向“桌面工作入口”。一旦消息、历史上下文、站点分发和可分享协作都接上，AI 的默认使用场景就更像操作系统层能力。
- 一句话点评：真正的产品壁垒，不只是模型更强，而是用户日常会不会越来越离不开这个入口。
- 来源链接：
  - [OpenAI Help Center：ChatGPT Release Notes](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)

### 3. 【近7天仍在发酵｜Agent 编程｜2026-08-19】Cursor 把云端 Agent 做成会盯 PR、看 Slack、跑定时任务的持续执行系统

- 发生了什么：Cursor 于 `2026-08-19` 发布 `Cloud Agents and Cursor Harness Improvements`。官方写明，云端 Agent 现在可以订阅事件源、在 PR 或 Slack 线程出现更新时自动唤醒、持有一个持续目标直到完成，还能把子 Agent 分配到各自独立的虚拟机里运行，减少多 Agent 并行时的上下文和环境冲突。
- 为什么重要：今年很多编程 Agent 还停在“帮你写一次代码”，Cursor 这次更像把 Agent 进一步推成持续值守的开发系统。能订阅、能追目标、能在隔离环境里分身干活，才更接近真实软件团队流程。
- 一句话点评：编程 Agent 赛道开始比拼的，已经不是会不会补全，而是谁先把“自动继续干下去”做成熟。
- 来源链接：
  - [Cursor：Cloud Agents and Cursor Harness Improvements](https://cursor.com/changelog/08-19-26)

### 4. 【近7天仍在发酵｜企业隐私 / 安全｜2026-08-19】OpenAI 为 frontier models 预览 Zero Data Retention 新方案

- 发生了什么：OpenAI 于 `2026-08-19` 发布 `Offering Zero Data Retention for frontier models`，宣布为符合条件的 API 客户继续提供 `ZDR`，并预览 `Private Safety Processing`。官方说明，这套方案希望在不让 OpenAI 人员查看留存内容的前提下，仍能跨多轮交互做自动化安全识别；技术白皮书和 rollout 计划将从 `2026 年 9 月` 开始推进。
- 为什么重要：随着长链路 Agent 越来越常见，企业最担心的不是“模型能不能干”，而是“敏感数据能不能不被留”。如果 ZDR 和更强安全系统能同时成立，企业把高价值工作流接给前沿模型的门槛会进一步下降。
- 一句话点评：AI 真要吃进企业核心流程，隐私承诺必须和能力升级一起交付。
- 来源链接：
  - [OpenAI：Offering Zero Data Retention for frontier models](https://openai.com/index/offering-zero-data-retention-for-frontier-models/)

### 5. 【近7天仍在发酵｜商业化入口｜2026-08-18】OpenAI 把 ChatGPT Ads 扩到 31 个欧洲市场

- 发生了什么：OpenAI 于 `2026-08-18` 宣布，`ChatGPT Ads` 将在下周扩展到 `31` 个欧洲国家，包括德国、法国、西班牙、意大利、荷兰、瑞典、挪威、丹麦和奥地利。官方同时说明，广告只面向 `Free` 与 `Go` 计划展示，`Plus`、`Pro` 与 `Enterprise` 仍保持无广告；目前广告主主要通过 OpenAI Ads Solutions 团队、代理和技术合作伙伴接入，自助版 `Ads Manager` 将在今年夏天稍后上线。
- 为什么重要：这不是简单的市场扩张，而是 OpenAI 在继续把 ChatGPT 的商业模式和产品分层做实。免费层广告、付费层免广告、广告后台逐步开放，意味着 ChatGPT 正越来越像一个成熟平台，而不只是单一聊天产品。
- 一句话点评：AI 产品的下一轮竞争，既是能力战，也是入口和变现结构战。
- 来源链接：
  - [OpenAI：ChatGPT Ads expands across Europe](https://openai.com/index/chatgpt-ads-expands-across-europe/)
