### 1. 【模型发布｜9月25日｜近7天仍在发酵】Perceptron Mk1.5 发布，音视频与工具调用接入具身任务

- **发生了什么：**Perceptron 发布 Mk1.5，新增原生音频、视频目标追踪及工具调用；官方平台和新版 SDK 已可用。
- **为什么重要：**它把感知、搜索与动作工具接进同一任务流程，面向无人机、机器狗、眼镜和手机等设备。
- **一句话点评：**能识别画面只是起点，接到设备后能否稳定完成任务才是重点。
- **来源：**[Perceptron 官方发布公告](https://www.perceptron.inc/blog/introducing-perceptron-mk1-5)，发布日期2026-09-25；检索日期2026-09-28。
- **证据边界：**跨设备无需针对平台重新训练是厂商表述，仍需向模型提供设备控制工具；不等于任意硬件即插即用。未将厂商基准优势写成独立验证结论。官方公告标注32K多模态上下文，本期不采用聚合站的37K数字。

### 2. 【产品更新｜9月25日｜近7天仍在发酵】Claude 开放插件提交门户，开发者可以跟踪审核与使用情况

- **发生了什么：**Anthropic 为付费 Claude 开发者开放目录提交门户，支持提交远程 MCP 连接器或 GitHub 插件包。
- **为什么重要：**开发者可以在同一流程查看安全检查、审核反馈和上线后的使用分析，插件分发路径更完整。
- **一句话点评：**做出一个连接器之后，还得让用户找得到、装得上、持续用。
- **来源：**[Anthropic 官方公告](https://claude.com/blog/build-plugins-for-claude)，发布日期2026-09-25；检索日期2026-09-28。
- **证据边界：**插件需通过审核，随后由开发者决定发布时间；Claude 与 Claude Code 的统一发现体验仍将在未来几周推出，不能写成已全面完成。旧技能、连接器和插件无需立即迁移。

### 3. 【多模态｜9月24日｜近7天仍在发酵】Gemini 3.8 Live Avatar 正式可用，边对话边执行后台工具

- **发生了什么：**Google 在 Gemini Enterprise 正式提供 Gemini 3.8 Live with Live Avatar，支持同步口型与异步工具调用。
- **为什么重要：**企业对话代理可同时处理音视频，并在后台查数据或执行任务时持续与用户交流。
- **一句话点评：**实时分身的价值不只在形象，更在对话能否顺畅衔接真实业务。
- **来源：**[Google Cloud 9月24日公告](https://cloud.google.com/blog/products/ai-machine-learning/gemini-3-8-live-with-live-avatar-is-now-generally-available/)、[Google 模型团队公告](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-8-live-with-live-avatar/)。检索日期2026-09-28。
- **证据边界：**自定义形象仅向企业白名单开放；Extended Thinking 仍为私有预览。正式可用不意味着普通 Gemini 消费者账户均可使用。本条是实时音视频对话能力，区别于9月26日报道的 TTS 语音生成模型。
