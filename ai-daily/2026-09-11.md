## 日报正文

### 1. 【Agent 平台｜2026-09-10】OpenAI 推出 Agents API 公测，一次调用运行托管云端 Agent

- 发生了什么：OpenAI 于 `2026-09-10` 发布 `Agents API` 公测。开发者可在一次 API 调用中指定任务、模型、工具和环境，使用与 Codex 相同的 Agent harness；平台支持 OpenAI 托管沙箱、自有基础设施及第三方沙箱，并内建长会话上下文压缩、工具搜索、程序化工具调用和多 Agent 协作。
- 为什么重要：企业过去要自行拼接模型、工具、状态管理、沙箱和任务恢复。Agents API 把这层运行底座变成托管服务，让竞争焦点从“能否写出 Agent”转向“能否稳定运行数小时或数天”。
- 一句话点评：Agent 平台的分水岭不再是多调一次工具，而是长任务能否持续、隔离、恢复并被开发者真正集成。
- 来源：[OpenAI：Introducing the Agents API](https://openai.com/index/introducing-the-agents-api/)

### 2. 【产品上线｜2026-09-10】ChatGPT Work 推出 Data agent，直连企业数据调查问题并生成仪表盘

- 发生了什么：OpenAI 于 `2026-09-10` 在 `ChatGPT Work` 推出 `Data agent`。它可连接 Redshift、BigQuery、Databricks、Snowflake、MongoDB 等数据源，也能引用 Google Drive 与 SharePoint 文件；用户可用自然语言追问、查看证据并生成可编辑、分享和刷新的交互式仪表盘。查询沿用连接账户现有的表、行和列级权限。
- 为什么重要：这让企业数据分析从“等待报表或写查询”变成对话式调查，同时保留语义层和既有权限边界，直接触及 BI 工具的核心工作流。
- 一句话点评：真正有用的数据 Agent，不只会画图，还要知道公司指标怎么定义、用户究竟有权看哪一行。
- 来源：[OpenAI：Now everyone can put data to work](https://openai.com/index/put-data-to-work/)

### 3. 【个人 Agent｜2026-09-08】Meta 上线 Muse，用独立安全虚拟机代办邮件、预订与购买

- 发生了什么：Meta 于 `2026-09-08` 在美国推出个人 AI Agent `Muse`，支持 iOS、Android、`muse.ai` 和 WhatsApp。Muse 可发送邮件、预订旅行、填写表单和处理长期目标；每位用户的 Agent 运行在独立 `Muse Secure VM` 中，所有联网动作须经隔离的 `Sentinel` Agent 审批，敏感操作还需用户确认，并提供完整审计记录。
- 为什么重要：Muse 把消费级 AI 从聊天界面推进到持续运行、持有上下文并操作外部服务的个人代理，同时用独立虚拟机、凭据隔离和双 Agent 审批正面处理权限风险。
- 一句话点评：个人 Agent 的成败，不只看它能代办多少事，更看用户是否敢把真实账户和长期目标交给它。
- 来源：[Meta：Introducing Muse](https://about.fb.com/news/2026/09/introducing-muse-personal-ai-agent/)
