## 日报正文

### 1. 【模型升级｜9月22日】Claude Opus 5.5 发布，百万上下文与更低价格服务长任务

- **发生了什么：**Anthropic 发布 Opus 5.5，支持百万 token 上下文，标准 API 每百万输入／输出为 4／20 美元。
- **为什么重要：**缓存读取每百万 token 为 0.20 美元，长任务可复用上下文；官方估算典型按 token 计费任务较 Opus 5 约省 40%。
- **一句话点评：**比较新模型，除了看能否完成任务，也要看做完一次到底花多少钱。
- **来源：**[Anthropic 发布公告](https://www.anthropic.com/claude-opus-5-5)、[官方产品与价格说明](https://www.anthropic.com/claude/opus)。
- **证据边界：**约 40% 是官方典型任务成本估算，不能写成所有 token 单价统一降 40%；标准输入／输出单价比 Opus 5 低 20%。Fast mode 为另一价格档。发布覆盖 Claude 付费用户、Claude Platform 及多家云平台，具体权限以账户为准。

### 2. 【模型发布｜9月22日】GPT‑6 Sol 与 Luna 上线，把新一代能力带入不同预算的工作流

- **发生了什么：**OpenAI 发布 Sol 与 Luna，进入 ChatGPT Work、Codex 和 API；Sol 输入／输出单价为 2／10 美元，Luna 为 0.10／0.50 美元，均按百万 token 计。
- **为什么重要：**两款模型提供不同能力与成本选择，开发者可用真实任务比较质量、耗时和开销，再安排批量工作。
- **一句话点评：**便宜模型是否划算，要把返工次数和工具调用成本一起算进去。
- **来源：**[OpenAI 发布公告](https://openai.com/index/introducing-gpt-6-sol-and-luna/)、[Sol 规格](https://developers.openai.com/api/docs/models/gpt-6-sol)、[Luna 规格](https://developers.openai.com/api/docs/models/gpt-6-luna)、[9月22日发布记录](https://community.openai.com/t/announcing-gpt-6-sol-and-gpt-6-luna/1399925)。
- **证据边界：**公告列明面向 Plus、Pro、Business、Enterprise、Edu 的 Work 与 Codex，Free／Go 可在桌面应用试用 Luna；公告时尚未进入 Chat。两款模型属于同一次发布，合并一条。这里列的是基础 token 价格，缓存、其他处理档位和工具费用需另看定价。

### 3. 【Agent 工具｜9月22日】NVIDIA Isaac ROS 5.0 免费开源，引入机器人开发 Agent Skills

- **发生了什么：**NVIDIA 在 ROSCon 发布 Isaac ROS 5.0，引入 AI Agent Skills，支持 ROS 2 Lyrical 与 Ubuntu 24.04。
- **为什么重要：**编程助手可辅助开发环境启动与迁移；新版改进 GPU 数据传输，帮助机器人感知流程减少不必要的数据搬运。
- **一句话点评：**机器人开发也开始交给 Agent 协助，价值要落在可验证的迁移和运行结果上。
- **来源：**[NVIDIA 发布公告](https://blogs.nvidia.com/blog/isaac-ros-5-0-agentic-open-source-robotics/)、[官方版本与技能说明](https://forums.developer.nvidia.com/t/nvidia-isaac-ros-5-0-is-officially-here/384027)、[GPU 迁移技术说明](https://developer.nvidia.com/blog/accelerating-a-ros-2-node-with-an-ai-agent-and-nvidia-isaac-ros/)。
- **证据边界：**这是机器人软件开发栈发布，不是新机器人基础模型。GPU 零拷贝依赖运行条件与通信两端支持，不能推断所有设备或工作流都会加速。
