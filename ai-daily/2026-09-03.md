## 日报正文

### 1. 【模型发布｜2026-09-02】Google 发布 Gemini 3.8 Flash 和 3.8 Flash Cyber，主打 Agent 编程与网络安全

- 发生了什么：Google 于 `2026-09-02` 发布 `Gemini 3.8 Flash` 和 `Gemini 3.8 Flash Cyber`。官方称 `3.8 Flash` 是“目前最强的推理与编码 Flash 模型”，价格维持在 `0.75 美元 / 百万输入 tokens` 与 `3.75 美元 / 百万输出 tokens`；`3.8 Flash Cyber` 面向可信防御方开放，重点用于漏洞发现与自动补丁。
- 为什么重要：这不是单纯小版本递增，而是把“低成本 + 长链路 Agent + 专项安全能力”打包推进，直接冲着真实开发与安全工作流去。
- 一句话点评：当低价工作马模型也开始追平更贵前沿模型，开发者默认选型会被重新洗牌。
- 来源：[Google：Introducing Gemini 3.8 Flash and 3.8 Flash Cyber](https://blog.google/innovation-and-ai/models-and-research/gemini-models/3-8-flash-and-3-8-flash-cyber/)

### 2. 【产品更新｜2026-08-31】OpenAI 宣布 ChatGPT Ads 年化营收跑到 10 亿美元，并把自助投放扩到印度、欧洲和中东北非

- 发生了什么：OpenAI 于 `2026-08-31` 宣布，`ChatGPT Ads` 在上线不到 `200` 天后达到 `10 亿美元` 年化营收运行率；自助投放 `Ads Manager` 当天开始扩展到 `印度`、`欧洲`、`中东` 和 `北非`。官方同时表示，广告支持的是 `10 亿+` 周活跃用户所在的免费层访问。
- 为什么重要：这意味着 ChatGPT 的商业化已不只是测试项目，而是正式进入全球扩张期，并开始影响更多品牌如何把 AI 对话入口当成流量和转化渠道。
- 一句话点评：AI 产品竞争现在不只比模型，还在比谁更快把入口变成成熟商业系统。
- 来源：[OpenAI：A milestone in expanding access to AI](https://openai.com/index/expanding-access-to-ai-with-chatgpt-ads/)

### 3. 【Agent 编程｜2026-09-02】GitHub Copilot App 和 CLI 的内容排除策略正式可用，敏感代码不再默认进 Agent 上下文

- 发生了什么：GitHub 于 `2026-09-02` 宣布，`GitHub Copilot app` 与 `Copilot CLI` 现在会遵守企业、组织和仓库管理员配置的 `content exclusion policies`，被排除的文件不会再被 Copilot 用作上下文；该能力面向 `Copilot Business` 与 `Copilot Enterprise`。
- 为什么重要：Agent 编程要进企业，前提不是先更聪明，而是先别把不该看的代码带进去。这个能力补的是企业真正关心的安全底线。
- 一句话点评：开发者 AI 的下一轮渗透，核心不是多会写，而是多会守边界。
- 来源：[GitHub Changelog：Content exclusions generally available in Copilot app and CLI](https://github.blog/changelog/2026-09-02-content-exclusions-generally-available-in-copilot-app-and-cli/)

### 4. 【Agent 编程｜2026-09-01】GitHub Copilot 代码审查开始支持直接批准 PR，审批动作进入预览

- 发生了什么：GitHub 于 `2026-09-01` 发布 `Copilot code review can now approve pull requests`。Copilot 现在会在每次代码审查概览里给出 `approval assessment`，管理员也可以在企业、组织或仓库级开启让 Copilot 直接提交 `approval`；该功能目前面向 `Pro`、`Pro+`、`Max`、`Business` 与 `Enterprise` 计划开放 `public preview`。
- 为什么重要：这让 Copilot 从“会挑问题的 reviewer”继续前进一步，开始触碰真实审批链路。哪怕默认关闭，它也在重画代码审查的人机分工边界。
- 一句话点评：只要 AI 能进入 PR 批准环节，代码评审工作流就不再只是辅助关系。
- 来源：[GitHub Changelog：Copilot code review can now approve pull requests](https://github.blog/changelog/2026-09-01-copilot-code-review-can-now-approve-pull-requests/)

### 5. 【网络安全落地｜2026-09-02】Google 推出 Fairwind Program，把 Gemini 3.8 Flash Cyber 与 CodeMender 交给可信防御方

- 发生了什么：Google 于 `2026-09-02` 启动 `Fairwind Program`，面向政府机构、关键基础设施运营方和核心技术平台开放受限访问，把 `Gemini 3.8 Flash Cyber` 与 `CodeMender` 组合起来，用于自动发现、验证并修复漏洞。官方披露该项目已有 `650+` 参与伙伴。
- 为什么重要：高能力网络安全模型真正落地，关键从来不是“能不能做”，而是“给谁做、在什么控制条件下做”。Fairwind 给出了一个受控部署路径。
- 一句话点评：最敏感的 AI 能力一旦开始带着访问闸门落地，行业就进入“可用但不完全开放”的新阶段。
- 来源：[Google：Google’s Fairwind Program: Cyber defense tools for trusted partners](https://blog.google/innovation-and-ai/technology/safety-security/fairwind-program/)
