## 日报正文

### 1. 【模型发布｜2026-09-18】Kimi K3 登陆 Amazon Bedrock，2.8 万亿参数与百万上下文进入企业云

- 发生了什么：AWS 于 `2026-09-18` 宣布 Moonshot AI 的 `Kimi K3` 在 Amazon Bedrock 全面可用。官方称其为首个达到 `2.8 万亿参数` 的开放权重模型，支持原生视觉、`100 万 token` 上下文和显式提示缓存。
- 为什么重要：企业可在 Bedrock 的访问控制、加密和审计边界内使用 Kimi K3 处理大型代码库、扫描文档与长流程 Agent 任务，不必自行托管超大模型。
- 一句话点评：开放模型争夺企业市场，决定胜负的不只是榜单，而是能否进入成熟云平台并把长上下文成本压下来。
- 来源：[AWS：Kimi K3 by Moonshot AI is now generally available on Amazon Bedrock](https://aws.amazon.com/about-aws/whats-new/2026/09/moonshot-ai-kimi-k3-on-amazon-bedrock/)

### 2. 【Agent 基建｜2026-09-18】Amazon Bedrock AgentCore Runtime V2 上线，冷启动稳定在约 2 秒

- 发生了什么：AWS 推出新一代 `AgentCore Runtime`。它按需分配并回收会话内存，通过快照恢复 Agent 环境；官方测试中，`200MB` 至 `2GB` 容器的 P75 冷启动稳定在 `1.9–2.0 秒`，旧版为 `5.4–30 秒`。
- 为什么重要：长时间、事件驱动和大量并发的 Agent 不再必须为峰值内存持续付费，启动延迟也不再随镜像体积和并发明显恶化。
- 一句话点评：Agent 真正进入生产后，模型只是上层，启动、隔离、内存和计费才是能否规模化的底座。
- 来源：[AWS：The new AgentCore Runtime is now available in Amazon Bedrock AgentCore](https://aws.amazon.com/about-aws/whats-new/2026/09/new-agentcore-runtime-generally-available/)

### 3. 【AI 基建｜2026-09-18】SageMaker HyperPod 推理网关上线，首 token 延迟最高降 82%

- 发生了什么：AWS 发布 `SageMaker HyperPod Inference Gateway`，以 Kubernetes 原生 EKS 插件读取 GPU、KV cache、队列和 LoRA 驻留状态，把请求路由到最合适的模型 Pod；官方称首 token 延迟最高可降低 `82%`。
- 为什么重要：现有 vLLM、SGLang、TGI 等 OpenAI 兼容模型服务无需修改应用代码，就能减少 GPU 空转和排队，直接改善大模型推理的延迟与成本。
- 一句话点评：推理成本优化正从“换更快的 GPU”转向“让每个请求更聪明地找到空闲算力”。
- 来源：[AWS：Introducing Amazon SageMaker HyperPod Inference Gateway](https://aws.amazon.com/blogs/machine-learning/introducing-amazon-sagemaker-hyperpod-inference-gateway/)

### 4. 【产品上线｜2026-09-17】Amazon Connect Talent 上线，用 AI Agent 批量完成面试与评估

- 发生了什么：AWS 推出 `Amazon Connect Talent`，面向大规模招聘团队提供 AI 主导的面试、岗位化评估、候选人评分、完整转录和评分依据，招聘人员保留最终决策权。
- 为什么重要：它把 AI 从写 JD、筛简历推进到可配置、可审计的面试工作流，并允许候选人在任意时间、任意设备上完成评估。
- 一句话点评：招聘 AI 的产品边界正在从“辅助 HR”走向“承接流程”，透明评分和人工终审会成为采用门槛。
- 来源：[AWS：Reduce time-to-hire for quality candidates with AI-powered Amazon Connect Talent](https://aws.amazon.com/blogs/machine-learning/reduce-time-to-hire-for-quality-candidates-with-ai-powered-amazon-connect-talent/)

### 5. 【Agent 能力｜2026-09-17】Claude 已“主导”Anthropic 26% 模型研发任务

- 发生了什么：Anthropic 公布首版 `R&D Automation Index`：截至 `2026 年 8 月`，Claude 可从高层提示出发、在人工监督下端到端主导 `26%` 的模型研发工作；达到“协作”或更高自动化级别的工作超过 `90%`，但尚无任务达到完全自主。
- 为什么重要：这是头部实验室首次用统一任务树量化 AI 参与下一代模型研发的程度；Anthropic 同时披露其最常用内部平台约有 `3 万个` Agent 同时参与研发与工程工作。
- 一句话点评：AI 辅助造 AI 已经从故事变成可测量的生产过程，但“26% 主导”不等于无人监督，更不等于递归自我改进已经实现。
- 来源：[Anthropic：Measurements for understanding the pace of AI development inside frontier labs](https://www.anthropic.com/institute/measuring-pace-of-ai-development)
