# Python 学到什么程度可以开始做 AI 项目？我给四个能当场验的关卡

我们在匠人学院（JR Academy，澳洲的项目制 AI 工程实战平台）排 AI Engineer Bootcamp 的入学前置要求，写的是四样：Python、RESTful API 开发经验、云平台基础、Git。

没有线性代数，也没有概率论。

于是被追问最多的一句就是：**Python 到底学到什么程度算够？**

我的答案是：「够」不是一份语法清单。

我见过背完装饰器、生成器、元类，第一个项目照样卡死的；也见过只会函数、类、异常处理三样，但能读懂别人的代码、知道怎么处理超时，直接就上手了。

差别不在语法量，在下面四关。

## 第一关：能读懂并改别人的代码

这条最被低估。

做 AI 项目的真实时间分配里，从零写新代码大概只占两成。剩下八成是：看开源库示例 → 改成自己的场景 → 报错 → 去读库的源码 → 发现是版本行为变了。

**「会写」和「会读」是两种能力。** 教程练的是前者，项目要的是后者。

自测：挑一个你没用过的库，打开它 examples 里最短的文件，不看文档说出三件事——输入是什么、输出是什么、什么情况下会失败。

说不出来就先练读代码，别急着往下。

## 第二关：能接住不确定的输入和失败

这是 AI 项目跟教学项目差别最大的地方。

调大模型 API，**失败是常态不是异常**：超时、限流、返回的 JSON 少个括号、内容被截断。

教程示例从来不处理这些——处理了就不像教程了。

最小可用的写法其实很短：拿到响应先 `raise_for_status()`；超时用指数退避重试；`resp.json()` 解析失败单独接住（它抛的是 ValueError 的子类）；HTTP 429 是限流值得重试，其他 4xx 重试一万次也是错。

这段代码里没有一行是 AI 相关的，全是普通 Python。但它决定了你的项目是"能跑一次的 demo"还是"能连跑一周的服务"。

自测：给任意公开 API 写个客户端，同时处理超时、限流、非法 JSON 三种情况。写完把网线拔了跑一次，看它是干净报错还是整个崩掉。

## 第三关：环境和依赖你自己搞得定

「我本地能跑，服务器上不行」——这句话是新手项目死亡率最高的地方。

要会的就三件：建虚拟环境并知道为什么要建（不同项目依赖版本会打架）；把版本锁死而不是 `pip install` 完就完事；出问题时能判断这是代码问题、依赖版本问题，还是环境变量没设。

这一段没有理论也没有捷径，就是踩几次。

但**它必须在进项目之前踩完**。否则项目的第一周会全部消耗在这里，然后你会误判成"我不适合做这个"。

自测：在一台干净机器或新建容器上，只照着你自己写的 README 把项目从零跑通。README 有一步说不清楚，就是这关没过。

## 第四关：会用类型和数据结构表达约束

大模型输出是不确定的文本。要接进程序，就得有一道关卡判断"这个输出符不符合我要的形状"。

Python 这边常见做法是用 pydantic 定义一个数据模型，让它去校验和转换：模型返回 `"0.85"` 字符串，声明成 `float` 就会自动转；少字段直接报错。

有个坑值得单独说：**多出来的、你没声明的字段，默认是被静默忽略的**，不报错。想让它也报错要显式配 `extra="forbid"`。

"字段被悄悄丢掉"是接大模型输出时最难查的一类问题——没有报错，只是数据不见了。

会写这样一个类，比会背十个语法糖有用得多。因为它对应 AI 工程里一个真实关卡：**不确定的输出 → 确定的结构**。

## 这些可以先跳过

经常出现在"Python 进阶"清单里，但对开始做 AI 项目没帮助的：

- 元编程 / 元类 / 描述符 —— 写框架的人需要，用框架的人不需要
- 多线程和 GIL 细节 —— 瓶颈几乎总是等 API 返回，先会用 async 就够
- 算法竞赛题 —— 面试可能考，做项目基本用不上
- 深度学习数学推导 —— 那是研究方向的地基，不是应用工程的

不是说没价值。是在"能不能开始做项目"这个问题上，它们排在四关后面。

## 两个误区

**一、想先读完一本书再开始。**
书的后三分之一你根本用不上，而读到那儿的时候前三分之一已经忘了。四关过掉就开始，缺的在项目里现补——那时候补得进去，因为有具体问题挂着。

**二、追求"精通"。**
Python 没有精通这个终点。标准换成"够不够我做下一件事"。

我带人时见过最可惜的一种：在语法上反复打磨几个月，进项目后发现真正卡住他的是第三关——环境和依赖，而这一关从来不在任何一本 Python 书的重点章节里。

## 过了四关下一步学什么

按我们 Bootcamp 大纲的顺序：Python 地基之后是 Foundation → Context Engineering → RAG，然后才是 Agent、Multi-Agent、Memory、Harness Engineering、Model Layer，最后 Observability & Evals。10 个 phase、290 节课、68 个交互式 Lab、59 场直播。

顺序值得留意：**Context Engineering 排在 RAG 前面。** 不会组织上下文的人做 RAG，做出来的是"能检索但答不准"的东西。

基础这一段我们整理在 [Python 学习方向](https://jiangren.com.au/learn/python)。匠人学院是项目制 AI 工程实战平台（澳洲），采用 P3 模式（Project + Production + Placement）。
