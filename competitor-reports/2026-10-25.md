## §4. 行业动态（对 JR 课程的影响）

- **Anthropic Claude Duet 研究预览**（2026-10-21，[releasebot.io](https://releasebot.io/updates/anthropic/claude)）— Pro/Max 用户可用，Claude 主动作为 Agent 工作，是从"聊天 AI"向"主动 Agent"的重大转型。**JR 影响**：AI Agent Bootcamp 应增加 Claude Duet 实战章节，强调"主动 Agent 工作流"在实际工作中的应用。
- **Kimi K3.1 Pro 发布**（2026-10-23，Moonshot，[aiweekly.co](https://aiweekly.co/ai-news-today)）— 全面上线 Kimi.ai / Kimi Work / Kimi Code / API，开源权重承诺 11 月 4 日发布。**JR 影响**：中文 AI 工具在 Agent 能力上持续追赶 OpenAI；JR 课程的"中文 AI 工具对比"模块需更新加入 Kimi K3.1 Pro。
- **MiniMax M3.1 Flash 开放**（2026-10-23，API 定价 $0.15 input / $0.60 output 每百万 token）— 价格远低于主流模型，正在压低推理成本基准。**JR 影响**：低成本 API 让学员构建个人项目门槛更低，是课程实战场景更新的好材料。
- **OpenAI 模型上线 Google Cloud**（2026-10-22，私测阶段，[stocktwits.com](https://stocktwits.com/news-articles/markets/equity/elon-musk-jensen-huang-mark-zuckerberg-agree-ai-faces-bottlenecks-but-differ-on-why/cZUGPmZRBUB)）— OpenAI × Google Cloud 联合，多云部署成常态。**JR 影响**：JR 的 Cloud + AI 部署课程应涵盖多云 AI 接口，避免课程只讲 AWS 生态。
- **Avalon-M1 发布**（2026-10-23，General Reasoning，基于 Nemotron 3 + RLCR 训练）— Agent 协同组织模型，代表 Agent 从单体走向群体协同方向。**JR 影响**：Agent 架构设计内容方向值得更新，加入"多 Agent 协同"视角。
- **The Rundown AI / TLDR AI / Ben's Bites** — 本周 10-19~25 具体期刊内容无法直接获取；上述行业动态综合自多个 AI 聚合器，已涵盖本周主要信号。
