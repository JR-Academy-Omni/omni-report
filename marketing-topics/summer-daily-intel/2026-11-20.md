# Summer 每日选题情报｜2026-11-20

> 本次仅交付「选题名称、选题主要内容、官方来源链接」。已与本目录截至 2026-11-19 的历史选题（含 11 月 4 日至 18 日半月汇总）比对去重；以下页面均于 2026-11-20 核验为仍可访问的官方课程、学习路径或认证页面。Microsoft 正式认证考试通常收费，费用以预约地区实时页面为准。

## 选题 01｜Anthropic 免费课：Building with the Claude API

- **选题主要内容**：面向有 Python 基础的开发者，系统学习 Claude API、多轮对话、结构化输出、工具调用、RAG、MCP、Claude Code、Computer Use 和 Agent 工作流；课程页面标注免费注册。
- **官方来源链接**：[Anthropic 官方课程页](https://anthropic.skilljar.com/claude-with-the-anthropic-api)

## 选题 02｜Anthropic 免费课：Claude Platform 101

- **选题主要内容**：从第一次 API 调用开始，覆盖模型选择、Agent Loop、工具、Extended Thinking、Skills、MCP、上下文管理、托管 Agent 与 Claude Code；课程免费，但运行部分示例需要 Anthropic Console 账户及少量预付 API Credits。
- **官方来源链接**：[Anthropic 官方课程页](https://anthropic.skilljar.com/claude-platform-101)

## 选题 03｜Anthropic AI Fluency 免费课：完成测验可拿结课证书

- **官方来源链接**：[Anthropic 官方课程页](https://anthropic.skilljar.com/ai-fluency-framework-foundations?via=free)

- **官方来源链接**：[Anthropic 官方课程页](https://anthropic.skilljar.com/claude-in-amazon-bedrock)
