## 选题 2｜AWS Card Clash 新增免费 Contests 与 Tournaments

**事实卡**
- AWS Training and Certification 于 8 月 25 日正式发布。
- AWS Card Clash 是免费、mobile-first 的架构设计游戏，使用 AWS Skill Builder 账号即可参与。
- Contest：统一架构题池、AI 对手、限时排行榜，可重复挑战提高最好成绩。

**文案 A｜AWS最新学习产品动作**

AWS 8月25日刚把Cloud Architecture做成了“排位赛”🔥：Card Clash正式新增Contests和Tournaments，而且游戏本身免费，用AWS Skill Builder账号就能参加。

这次不是再塞一套视频课。AWS把真实Solution Diagram拆成卡牌位，你要判断EC2、S3、Lambda、Database、Networking等service该放在哪里，才能补完整个architecture。答对不是靠记一句定义，而是要看懂数据怎么走、service之间怎么配。

新加的两种模式也完全不同👇
⚡Contest：所有人跑同一组架构挑战，对AI完成任务，按stars、quality score和完成时间排榜；做完还能重跑，用最好成绩计分。
⚔Tournament：玩家直接对战，先Swiss phase，再进elimination bracket，系统自动处理pairing和rank。

这反映了AWS今年培训路线的一个明显变化：从“看懂Cloud”继续往“在scenario里作判断”推。对正在准备Cloud Practitioner、Solutions Architect，或者总觉得service都认识但架构题不会选的人，游戏化练习比机械背表更容易暴露知识断点。

注意Card Clash不是AWS Certification，官方这次公告也没有承诺个人玩完就发badge。它的价值是免费的架构训练和可组织的竞赛机制，别把性质写错。

AWS刚更新的免费Card Clash正好打这个卡点。它不是让你继续背service definition，而是把架构缺口做成卡牌位：面对一个真实solution，你需要选择合适的AWS service补进去，再看整个设计能不能成立。

8月25日新增的Contest和Tournament，把个人练习变成了两套玩法。想自己练，可以进Contest跑统一题池、对AI挑战排行榜，而且允许重复做，用最佳成绩计分；想组织班级、团队或community活动，可以开Tournament，让参与者经过Swiss round和淘汰赛直接对战。

对Cloud学习者来说，这种形式最有用的不是“赢”，而是快速发现自己在哪些架构模块判断不稳：compute选型、storage组合、network路径、database适配，都会在放错卡时直接暴露。

它是AWS Skill Builder里的免费Architecture Design Game，不是正式cert，也不要把排行榜当成credentials。准备AWS考试、刚补Cloud Architecture或想找轻量练习的人，可以把它当成看课之外的一组实战题。
