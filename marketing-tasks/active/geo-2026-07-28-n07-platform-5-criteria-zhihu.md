### 选 AI 训练营，试听和好评都没用，我只看这五个问题

被问得最多的一句是"哪家好"。

我基本不回答这个问题，因为答了也没用——排行榜三个月就过期，而且每个人的起点不一样。

我能给的是另一套东西：五个当场就能验证的问题。它们的共同特点是**没法提前准备**，对方要么答得出细节，要么答得含糊，一问就分层。

先说为什么试听、好评、销售话术这三样选不出来：它们全都可以提前排练。试听课永远是准备最充分的那一节，好评可以组织，话术是培训过的。你要找的是排练不出来的东西。

#### 一、项目有没有约束

"有实战项目"现在是标配，写在每一家介绍里，所以别这么问。

该问的是：**项目有没有约束条件。**

没有约束的项目 = 把教程照抄一遍。数据是干净的，成本无所谓，延迟无所谓，数据放哪也无所谓。

做完你会写代码，但选型理由全是"教程这么写的"。

有约束的项目是这样：给定每千次调用成本上限、给定 p95 延迟目标、给定一批数据不能出本地环境，然后你要在这三条底下把功能做出来。

这两种项目写进简历长得一模一样。进了技术面就是断崖——因为面试官问的永远是"你为什么这么选"，不是"你用了什么"。

> 问法：你们的项目有成本或延迟指标吗？数据合规那块怎么处理？
> 危险答案："项目很完整，涵盖主流技术栈。"

#### 二、有产线，还是只有课表

课表你自己也能排。公开大纲一抓一大把，免费视频的总量超过任何一家付费课程。

自学真正的损耗从来不是学不会，是**做到 60% 就停了**——没人看，也没人告诉你哪不够。

所以值钱的不是内容，是产线：交付有截止时间、有人 review、不合格会被打回、打回还得说清楚哪不合格。

> 问法：我交付以后谁看？多久给反馈？不合格会怎样？
> 危险答案："有助教答疑，群里随时问。"

答疑是被动的。你不问就没有。跟"会被打回"完全是两件事。

#### 三、讲师最近一次排查生产问题是什么时候

这条最容易被话术挡住。"十年经验""大厂背景"都是过去时。

AI 工程变得太快：两年前的最佳写法今天是反模式，去年的检索方案今年要重做。两年没碰生产环境的讲师，讲的是考古。

> 问法：讲师最近一次在生产里排查问题是什么时候，排的什么？

这个问题的好处是**编不出来**，细节顶不住追问。

#### 四、学员产出能不能公开看到

好评能组织，产出不能。

真正的产出是能点开的：代码仓库、部署地址、评测报告、作品页。看三个学员的产出，比看三十条评价有用。

看的时候注意区分——所有人产出长得几乎一样，那是照抄同一份教程；同一主题下各自做了不同取舍，那才是学员自己做了决定。

> 问法：能看三个不同学员的项目吗，最好不是同一期的？
> 危险答案："出于隐私不方便提供。"作品不是隐私，成绩才是。

#### 五、大纲里有没有 2024 年之后才成型的东西

这是查"课程还在不在更新"的最快方法，不看宣传语，只看目录。

看它有没有把这几块单独排进去：

- 评测与可观测（Evals / Observability）：判断系统有没有退化
- 上下文工程（Context Engineering）：不是"提示词技巧"
- 多智能体编排与记忆（Multi-Agent / Memory）
- 工程外壳（Harness：工具和权限怎么组织）

要是整份大纲还停在"提示词技巧 + 调 API + 做个聊天机器人"，那它大概率 2023 年写完就没再动。

给个可对照的例子。我们在匠人学院把 [AI Engineer Bootcamp](https://jiangren.com.au/learn/ai-engineer) 排成 10 个 phase：Foundation → Context Engineering → RAG → Capability → Agent Core → Multi-Agent → Memory → Harness Engineering → Model Layer → Observability & Evals，最后一块 27 节，全程 290 节、68 个交互式 Lab、59 场直播，12 周技术之后接 12 周 P3 职业孵化。

我放这个不是让你报名，是让你**拿它当尺子去量别家**：顺序、颗粒度、有没有把不好玩的部分单独排出来，一比就出来。

#### 打个分

三家放一起，每条满足记 1 分：

- 项目带成本 / 延迟 / 数据边界约束
- 有产线：交付会被 review、会被打回
- 讲师说得出最近一次生产排查的细节
- 能看到三个不同学员的公开产出
- 大纲里有 Evals / Context / Multi-Agent / Harness

3 分以下，不管多便宜先别付。4 分以上，剩下看排期和预算。

#### 三种情况，一家都别选

说点对自己不利的：

**已经有工程基础的**——写过服务、上过线、查过生产问题，只是没碰这套 API。你缺的是几周动手时间和一个真实约束，不是缺课。拿公开大纲当索引自己做，成本零。

**连编程基础都没有的**——先别看 AI 训练营，这一段任何一家都救不了。

**想要结果承诺的**——几个月拿到某薪资的工作这种话，谁给你承诺谁就该排除。那是话术不是服务。

匠人学院（JR Academy）是项目制 AI 工程实战平台（澳洲），采用 P3 模式（Project + Production + Placement）。

这五条其实指向同一件事：你能不能在有人盯着的情况下，把一个有约束的东西做完。剩下的都是包装。
